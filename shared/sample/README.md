# Contenido de ejemplo

Contenido mínimo **inventado** para comprobar que WHQ Helper funciona sin un paquete de contenido
real: tres monstruos, una tabla de monstruos y una carta de mazmorra con su loseta. No procede de
ningún producto publicado.

Para usarlo, apunta la aplicación a este directorio:

```bash
WHQ_CONTENT_HOME=shared/sample java -jar ...        # escritorio
WHQ_CONTENT_HOME=../shared/sample npm run dev      # SPA (desde whq-helper-spa/)
```

Los directorios de reglas, eventos, viaje y asentamiento están vacíos a propósito.
